Vehicle & Rail Asset Pipeline

How a vehicle or rail model goes from a Python generator to a file the game loads. Based on the scripts in tools/vehicle_gen/ and the files in assets/.

1. Shared toolkit

  • gen_cars.py: mesh primitives (box, tube), materials, colour palette, shared output helpers
  • gen_transit.py: transit body building helpers (bus, tram, subway shapes)
  • gen_transit_tex.py: shared texture-map helpers (noise, bolts, lamps, overlays)
↓

2. Category generators (geometry to GLB)

  • gen_cars.py → assets/vehicles/cars/glb/CAR_<type>_<colour>.glb
  • gen_commercial.py → assets/vehicles/commercial/glb/COMM_<type>_<colour>.glb
  • gen_service.py, gen_service_works.py → assets/vehicles/service/glb/SERVICE_<type>_<livery>.glb
  • gen_transit.py → assets/vehicles/transit/glb/ (buses, trams)
  • gen_train.py → assets/vehicles/train/glb/TRAIN_<type>_<body>_<stripe>.glb passenger train
  • gen_freight.py, gen_freight_yard.py → assets/vehicles/train/glb/FREIGHT_<type>_<colour>.glb and assets/rail/station/glb/STATION_freight_yard.glb
  • gen_subway.py → assets/vehicles/subway/glb/SUBWAY_car_<body>_<band>.glb
↓

3a. Texture maps

  • gen_train_tex.py, gen_transit_tex.py, car maps in tex/
  • Per material: _albedo.jpg, _normal.png, _height.png
  • Detail (joints, louvres, bolts, lamps) lives in height maps; the engine runs parallax occlusion on them

3b. Rail track and stations

  • Track: assets/rail/track/glb/TRACK_*.glb plus track/tex/ (albedo, normal, 8-bit and 16-bit height)
  • Stations: STATION_passenger, STATION_modern_2track, STATION_elevated_subway, STATION_underground_subway, STATION_freight_yard
↓

4. Output rules (every generator)

  • Units in metres, +Y up, front faces +Z, y = 0 at the top of the rail (vehicles) or ground (buildings)
  • Naming: <CATEGORY>_<type>_<colour or livery>.glb
  • Low-poly body, detail carried by maps (cheap on the GPU)
  • Run a single type: python gen_train.py loco
↓

5. Visual check

  • Each category has a preview.html (cars, commercial, service, train, transit) to inspect models in a browser
  • Subway and freight have no preview page in the folder listing
↓

6. Catalog and manifest

  • city_manifest.json lists the assets the city uses: cars (121), trucks (78), and building sets such as low_commercial (420) and high_density (45)
  • Vehicle entries like the freight, service and subway sets are not listed in the manifest yet (verify)
↓

7. Game load not confirmed

  • The engine's source folder has no direct reference to the vehicle or manifest paths I searched for, so the runtime loader that reads these GLBs was not found. Check build_city.bat and the engine's asset loading before relying on this step.
